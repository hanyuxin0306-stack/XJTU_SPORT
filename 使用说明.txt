抢场无忧 · XJTU SPORT

直接使用
双击本文件夹内的 sport.exe，无需安装 Python。
填写本人的 NetID 和密码，选择日期、场馆、场地及时间，点击“启动任务”。
使用“停止任务”结束当前执行；关闭主窗口后，程序会收至系统托盘。
校园登录时的验证码或二次验证需在浏览器内手动完成；请保持 Microsoft Edge 和网络可用。

账号与配置
首次使用请自行填写账号密码，默认不保存。
如主动勾选“记住账号密码与所有设置”，程序会在本机生成 config.json。
其中密码仅使用 Base64 编码，Base64 不是加密；请勿分享 config.json。
config.example.json 是无账号、无密码的示例，可供参考；不复制也能启动程序。
分享日志或诊断信息前，请先检查其中的信息。

运行 Python 源码
程序入口为 sport.py。
在本目录打开 PowerShell：
  python -m venv .venv
  .\.venv\Scripts\python.exe -m pip install -r requirements.txt
  .\.venv\Scripts\python.exe sport.py

重新打包
在本目录的 PowerShell 中执行：
  .\build.ps1
已有依赖时可执行：
  .\build.ps1 -SkipInstall
脚本根据 sport.spec 生成 dist\sport.exe，并复制到本目录。
requirements.txt 为运行依赖，requirements-build.txt 包含额外的打包依赖。
个人配置不会嵌入 exe。
